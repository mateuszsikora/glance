# Code of conduct

We want Glance to be a welcoming, constructive project. Be respectful, assume good intent, give actionable feedback, and avoid harassment, discrimination, threats, or publishing another person's private information.

Project maintainers may edit or remove contributions and restrict participation when behavior harms the community. Report conduct concerns privately to `ms1qaz@gmail.com`. Reports will be handled as confidentially as practical.

This code of conduct applies in the repository and in public spaces where someone is representing the project.
